# test-assignment

Repository for test and sample projects. Each project lives in its own directory.

## Projects

| Project | Description |
|---------|-------------|
| [waitlist-nestjs](./waitlist-nestjs) | NestJS waitlist app with Apollo GraphQL |

More test projects will be added over time.

## Running a project

Each project has its own `package.json` and setup. Go into the project folder and follow its README, for example:

```bash
cd waitlist-nestjs
npm install
npm run start:dev
```
